# Mark capabilities

Decision: [ADR-0005](adr/ADR-0005-readme-visuals-toolkit.md). Each capability row states what it does; its tests and the live host measure it. `python3 scripts/check-capabilities.py` checks each Code file, supported-status test reference, and the complete literal Axum route inventory. CI executes the referenced tests; this guard does not prove live availability. Routes shared by capabilities are listed once under their primary owner.

## Operations

- Public probe: anonymous `GET https://mark.sylphx.com/badge/build-passing-brightgreen` and one URL per dialect return SVG. `/health.revision` is deploy proof, not product proof.
- The service has no database and no persistence. Live routes read public GitHub and npm APIs through a bounded in-memory cache.

Every Mark image is a URL. Put it in an <img> or Markdown image and it renders, with no install, no account and no token. Build one visually in the studio, or use the reference below.

Quick start

  1. Pick a URL below or build one in the studio.
  2. Paste it into your README as ![](URL).
  3. Commit. GitHub renders it.

Typing text: /typing

The same parameters as readme-typing-svg: lines (separated by ;), font, weight, size, color, background, center, vCenter, multiline, width, height, duration, pause, repeat, random, letterSpacing, separator, plus caret (default true; caret=false drops the blinking caret). Under prefers-reduced-motion the image shows the fully typed first line instead of moving.

![](https://mark.sylphx.com/typing.svg?lines=Hi%20there;Welcome%20to%20my%20README&center=true&width=520&height=50)

GitHub cards

github-readme-stats parameters: username, theme, show_icons, hide, hide_title, hide_rank, hide_border, border_radius, title_color, text_color, icon_color, bg_color, border_color, custom_title, card_width, layout (normal compact donut donut-vertical pie), langs_count, exclude_repo. The native routes are /api/v1/card/{stats|langs|streak|repo|stars}. Trophies (/trophy, or /?username=) take github-profile-trophy's theme, column, row, margin-w, margin-h, no-bg, no-frame, title and rank.

Live cards are cached on the server (about 4 hours) and at the edge. They are served stale while they refresh, and stale when GitHub is unavailable.

Star history: /svg

![](https://mark.sylphx.com/svg?repos=owner/repo&theme=dark)

A star-history.com URL works with only the host changed. GitHub shares star dates only with the people who can manage a repository, so the chart draws a curve for repositories Mark's server can read; for any other repository it shows today's total.

Profile card and deploy badge

/api/v1/mark/profile?text=Name&desc=Tagline, with theme, color, type (an art background), width and height.

/api/v1/mark/deploy?service=name renders a "deployed on Sylphx" badge.

Speed and reliability

Append .svg to any image path and it is served from the edge cache. Static images are immutable and cache for a year; live cards refresh about every four hours, are served stale while they refresh, and stay up when the upstream service is down. Every response has a strong ETag and answers If-None-Match with 304. Unknown parameters fall back to defaults, so a Mark URL never shows a broken image.

For tools and agents

GET /api (with no image query) returns the JSON endpoint index; GET /api/v1/catalog returns every form, style, theme, icon id and limit; GET /health returns the deployed revision.
